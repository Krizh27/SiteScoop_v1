# SiteScoop AI

SiteScoop AI is an open-source AI-powered website recovery and development agent.

## Technology Stack
- **Frontend**: React, Vite, JavaScript ES Modules, Tailwind CSS
- **Backend**: Node.js, Express.js, JavaScript ES Modules
- **AI**: OpenRouter API, Gemma 4, OpenAI-compatible API (Not implemented yet)

## Project Structure
- `client/`: React frontend application
- `server/`: Express backend API
- `workspace/`: Future workspace for recovered website files
- `docs/`: Project documentation

## Installation

1. Clone the repository
2. Install root dependencies (if any)
3. Navigate to `server` and run `npm install`
4. Navigate to `client` and run `npm install`
5. Create a `.env` file in the root directory based on `.env.example`

## Running

**Backend:**
```bash
cd server
npm run dev
```

**Frontend:**
```bash
cd client
npm run dev
```
